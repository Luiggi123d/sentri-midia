# Mídias do Sentri

Arquivos já aprovados dos posts do Sentri (Instagram, Facebook e TikTok), servidos como site para o agendador de posts buscar na hora de publicar. Cada pasta é uma semana. Os arquivos saem daqui depois de publicados.

Quem gera e envia: `maquina/publica_midias.py`, no repositório de marketing.
